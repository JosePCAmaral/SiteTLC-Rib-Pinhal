# TLC Ribeirão do Pinhal

Site do TLC (Treinamento de Liderança Cristã) de Ribeirão do Pinhal/PR,
da Paróquia Santuário do Divino Espírito Santo, Diocese de Jacarezinho.

- **Editar o conteúdo:** veja [COMO-EDITAR.md](COMO-EDITAR.md) (tudo fica em `src/conteudo.js`)
- **Rodar localmente:** `npm install` e depois `npm run dev`
- **Publicação:** automática no Cloudflare Pages a cada push na `main`

Feito com Vite + React + React Router.
